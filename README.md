# Windows Kernel Reconstruction

Projeto de reconstrução técnica do kernel do Windows a partir de binários, símbolos PDB, tipos e pseudocódigo descompilado.

## Conteúdo

- Inventário de tipos e estruturas
- Pseudocódigo descompilado
- Reconstrução em C

Nota: este projeto não contém nem pretende reproduzir o código-fonte privado original da Microsoft.
